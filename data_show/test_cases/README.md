# 合成測資索引

本目錄收九組合成訴願卷證,每組 `01_訴願書.pdf`、`02_原處分書.pdf`、`03_送達證書.pdf`、`04_訴願答辯書.pdf` 為合成輸入(送進系統走完整流程用),`05_訴願決定書.pdf` 為對應的官方訴願決定書全文(新北市政府公開系統的去識別化版本)。`example1b` 是 `example1` 的構造變體,沒有對應的真實決定書,改以 `05_預期決定結果.md` 記錄依法規推導的預期結果作為評測基準。`example3` 刻意不附送達證書(案由屬觀念通知,規格上不產生送達證書)。
